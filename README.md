# Netflix-Data-Analysis-Project

Overview:
- Business Analysis project of Netflix viewer and subscription data. Complete with multi-CTE SQL query (found in Netflix SQL Queries text file), visualizations and data analysis. Topics and skills demonstrated include missing data imputation logic, metric correlations using Pearson Correlation coefficients, business & market analysis and data visualization and analysis. 
- Full project including data sets, interview questions and business write-up PDFs can be found in the Project folder.

Summary of Files in Datasets & Analysis Folder:
- Dataset: Dataset used for Analysis and Correlations related to the BI-Questions, data cleaning and imputation for missing data.
    - Note: Imputed data, EDA process and data cleaning were completed using Excel, the SQL Queries file shows how we would accomplish the same using SQL.
- BI-Instructions & Data Dictionary: Background of the exercise & Data Dictionary defining all of our data elements. 
- BI-Questions: Business questions & answers related to insights driven from the Excel Dataset.
- BI-Competitive Analysis & Viz: Competitive analysis and write-up of Netflix subscription churn, market share analysis & consumer trends in the on-demand streaming service market and Tableau dashboards. NOTE: This analysis was written by me and used separate data which is not included in this folder. 

Goal:
This exercise was completed by me without use of any AI tools for assistance and the goal is to demonstrate my Business & Data Analysis skills, techncial SQL ability using CASE statements, CTEs and WINDOW functions effectively, Excel proficiency, and most importantly communication and ability to derive business-related insights from datasets using plain-english and oraganized, easily-digestible visualizations created within Tableau.
